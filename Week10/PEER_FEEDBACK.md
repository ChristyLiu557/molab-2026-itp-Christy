# Week10 — Peer feedback worksheet
Status: pending a real discussion. Do not submit invented feedback.

## Exchange format (about 10 minutes)
1. Explain the concept and show the Journal → New Entry → Detail flow.
2. Ask the classmate to describe what they think the app does.
3. Ask which feature is essential and which can wait.
4. Review their proposal in return and offer one specific suggestion.
5. Record one concrete revision to your own proposal, or explain why you retain the scope.

## Questions
- Does manually choosing one color make the memory personal?
- Is a typed place name helpful?
- Can the photo, color, and note fit into a simple entry flow?
- Is a local journal enough for this final project?
- Is the Week11–14 plan realistic?
